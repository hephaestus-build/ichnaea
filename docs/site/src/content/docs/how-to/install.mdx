Ichnaea is 0.x. Each release is a package tarball on GitHub, with a provenance attestation.
npm comes at 1.0.

## You need

- Node 24.3 or later
- pnpm
- the GitHub CLI, `gh`, to find and verify a release
- a project with a `package.json`

## Install

1. Make your project an ES module project:

   ```sh
   pnpm pkg set type=module
   ```

2. Find the newest release, verify it, and add it with zod. Run this at the root of your project:

   ```sh
   TAG=$(gh release view -R hephaestus-build/ichnaea --json tagName -q .tagName)
   gh release download "$TAG" -R hephaestus-build/ichnaea -p 'hephaestus-build-ichnaea-*.tgz'
   gh attestation verify "hephaestus-build-ichnaea-${TAG#v}.tgz" -R hephaestus-build/ichnaea \
     --signer-workflow hephaestus-build/ichnaea/.github/workflows/release.yml \
     --source-ref refs/heads/main --deny-self-hosted-runners
   pnpm add zod@4.6.7 "https://github.com/hephaestus-build/ichnaea/releases/download/$TAG/hephaestus-build-ichnaea-${TAG#v}.tgz"
   ```

   Do not skip the check. It shows that the release workflow of this repository built the tarball, and it catches a tarball that someone uploaded by hand.
   The check passes only for a tarball built by the release workflow on main.

3. Check that the command line tool runs:

   ```sh
   pnpm exec ichnaea --version
   ```

pnpm records the concrete URL and its integrity hash in your lockfile.
Releases are immutable, so the URL always serves the bytes you verified.
To pin an older release, set `TAG` by hand, for example `TAG=v0.1.0`.

zod is a peer dependency. zod 4.6 or later works, and 4.6.7 is the tested version.
Installing the package runs no script, because its `package.json` has none.
Each release also ships its SBOM, `sbom.cdx.json`, and `SHA256SUMS`. Both are attested.

## Update

Run the block of step 2 again. It finds, verifies and adds the newest release.
If you need a fix before the next release, ask for a patch release.

## Work on Ichnaea and your project together

1. In the Ichnaea checkout, build on every change:

   ```sh
   pnpm --filter @hephaestus-build/ichnaea build --watch
   ```

2. In your project, link the package of that checkout instead of the release tarball:

   ```sh
   pnpm link <path-to-ichnaea>/packages/ichnaea
   ```

3. When you are done, remove the link and install your release again:

   ```sh
   pnpm unlink @hephaestus-build/ichnaea
   pnpm install
   ```

Do not commit the link. It changes your `package.json` and lockfile to a path on your machine.

## Why there is no npm package yet

Each 0.x release comes from the release workflow, with an attestation that you can check.
At 1.0, the same package goes to npm.
