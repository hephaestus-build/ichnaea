First contracts: zod schemas and normative JSON Schema 2020-12 files (a writer schema and a tolerant reader schema per record) for cases, case sets, system configurations, suites, plans, trials, runs, measure cards, measure values, decisions, judges, labels, calibrations, monitors and findings. Includes RFC 8785 canonical hashing, the configuration identity and case-set digest over frozen member lists, a data policy on every field, an egress projection that drops unknown, unclassified and off-schema values, a tolerant reader, and shared fixtures with digest vectors from an independent implementation in another language.
