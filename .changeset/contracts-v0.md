First contracts: zod schemas and normative JSON Schema 2020-12 files (a writer schema and a tolerant reader schema per record) for cases, case sets, system configurations, suites, plans, trials, runs, measure cards, measure values, decisions, judges, labels, calibrations, monitors and findings. Includes RFC 8785 canonical hashing; the configuration identity, case digest and case-set digest, whose projections (what each hashes and what it leaves out, with the reason) have one home, `DIGEST_RULES`, also published as `fixtures/digest-rules.json`; a prompt template recorded beside its digest, which `verifyConfiguration` and `configurationIdentity` check it against (reading a record does not); a data policy on every field, an egress projection that drops unknown, unclassified and off-schema values, a tolerant reader, and shared fixtures with digest vectors computed by an implementation in another language that shares no code with this package.
