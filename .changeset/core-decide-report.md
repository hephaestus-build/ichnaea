First end-to-end slice. `core`: a plugin host with the seven lifecycle hooks, measure cards validated at load, and default-deny egress that only a governance plugin can open; a file store that writes each run once and atomically and refuses duplicate records; a monthly call ledger with a lock; the planner, which lists every trial before any call (a suite can give the cases of one slice more trials with `replicatesFor`), checks pools, families, arms, margins, measures and gates, tests every measure Ichnaea computes, and runs estimate-only with its reasons where no validated method can decide; and the `ichnaea` CLI with `import` (another runner's results, checked against the plan and the measure cards, no model calls), `schema` and `doctor`, exiting 2 on any error. `decide`: the decision rule (non-inferiority per primary measure, Holm on regressions, hard gates, coverage floors, a run of another plan or arms that differ beyond what the trigger varies is INVALID, a verdict that the missing-as-failure sensitivity analysis changes becomes INCONCLUSIVE, PASS only when every primary measure is shown non-inferior, a power statement on every run) and the `decide` command; INVALID always blocks. `report`: one view model rendered as a Markdown CI summary (every value escaped) and a static HTML report with each difference on an axis centred at 0, after a check that the decision recomputes from the stored records. Every decision states its scope ("on these 60 cases, beyond run-to-run noise"), and both reports print it next to the verdict. Contracts: suites gain `replicatesFor`; decisions gain `scope`; a CI policy has no action for INVALID; plans record why they are estimate-only and each planned trial's family; comparisons name their regression method and whether they are validated.
